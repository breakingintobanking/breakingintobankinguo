# documents/

Put actual downloadable files here (PDFs, .docx, .xlsx, etc.) and reference
them by relative path (`documents/your-file.pdf`) in `content/documents.json`.

Keep individual files well under 100MB (ideally under ~25MB) — GitHub Pages
is not built for large file hosting. If something's already hosted elsewhere
(Google Drive, a publisher's site), just point `file` at that URL instead of
copying the file in here.

There is a placeholder entry in `content/documents.json` pointing at
`documents/resume-template.docx`, which doesn't exist yet — replace or
remove it once you add real content.
