How to publish a change

    
    
      
  1. Add/edit/delete entries above.
    2. 
      
  2. For a new document, put the actual file in the documents/ folder first, and use that same relative path in the "File path" field.
    3. 
      
  3. For a new video, upload it to YouTube (unlisted is fine) and paste the link — don't put video files in the repo.
    4. 
      
  4. Click Download for whichever JSON changed, and save it over the existing file in content/.
    5. 
      
  5. Commit and push (git add . && git commit -m "Update content" && git push). GitHub Pages updates in a minute or two.
